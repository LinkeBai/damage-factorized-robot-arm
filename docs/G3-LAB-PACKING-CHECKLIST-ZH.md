# G3 真机实验设计、携带清单与执行手册

> 版本：2026-08-25 重写版
>
> 目标：以不混淆传感器角色、不改变冻结物理问题的方式，验证 IPWM 在关节锁定后的真机平面 pushing。
>
> 核心原则：先验证动力学机制，再验证眼在手自主闭环；顶置视觉、眼在手视觉和水平录像不得混用。

---

## 0. 当前系统事实

当前 IPWM 不是端到端图像模型。它接收关节位置、关节速度、平面物体位置与速度、控制动作、已诊断的锁定关节及锁定角，以及 K 条少样本支持转移。

当前真机脚本通过 `vision_pose_file` 读取：

```text
object_x_m
object_y_m
object_vx_m_s
object_vy_m_s
```

该接口没有自动证明状态来自眼在手相机。仓库已有相机内参标定、真机遥测和 readiness audit，但完整的“眼在手物块检测 → 相对坐标 → IPWM → 闭环推动”仍需验证。

因此 G3 分为两个不可混淆的阶段：

- **G3-A：FIRA 顶置视觉下的动力学机制验证**；
- **G3-B：眼在手视觉下的自主闭环验证**。

只有两阶段都通过，才能宣称端到端真机落地。G3-A 单独通过只能说明 IPWM 动力学机制在真机成立。

## 1. 三个摄像头的固定职责

| 摄像头 | G3-A | G3-B | 定量真值 |
|---|---|---|---|
| FIRA 正上方摄像头 | 为所有方法提供相同物体状态，同时记录真值 | 只记录独立真值，禁止反馈控制 | 是 |
| 眼在手摄像头 | 只同步录像和诊断 | 检测物块并向控制器提供物体状态 | 否 |
| 水平摄像头 | 接触、翻倒、安全事件和全景录像 | 同左 | 否 |

### 1.1 G3-A 信息流

```text
FIRA 顶置相机
  ├─→ 物体世界坐标 → Shared/IPWM → 动作 → 机械臂
  └─→ 独立保存轨迹与视频，用于定量评估

眼在手相机 → 只记录
水平相机   → 只记录
```

G3-A 回答：在可靠且对各方法完全相同的物体状态输入下，IPWM 是否比预算匹配 Shared 更好地预测和推动 D3 物块？

### 1.2 G3-B 信息流

```text
眼在手相机
  → 物块检测
  → 物块相对夹爪状态
  → Shared/IPWM
  → 动作
  → 机械臂

FIRA 顶置相机 → 独立真值，禁止反馈模型或控制器
水平相机       → 定性录像和安全复核
```

G3-B 回答：只依靠机械臂自身眼在手视觉和舵机状态，完整系统能否完成相同 pushing，并保留 IPWM 的收益？

### 1.3 禁止事项

- 禁止在 G3-B 眼在手丢失时用顶置坐标补帧；
- 禁止把顶置控制实验写成眼在手自主实验；
- 禁止用水平相机数据参与控制；
- 禁止试验后根据结果改变摄像头职责；
- 禁止把不同视觉来源的 trial 合并统计。

## 2. 场地坐标与 FIRA 标定

现有 FIRA 标定覆盖 220 cm × 180 cm 场地，已有：

- `groundmap.bin` 稠密像素到世界坐标映射；
- `calibration_auto.yml` 相机与畸变参数；
- 22 个场地地标；
- 主标定帧地标 RMS 约 0.784 cm；
- 最大地标误差约 1.266 cm。

它可以替代桌面 ArUco 世界坐标板，但不能免除实验当天复核。

### 2.1 当天局部复核

在机械臂工作区选择 9 个点：

```text
左上   中上   右上
左中   中心   右中
左下   中下   右下
```

每点执行：放置检测目标、用钢尺测量坐标、保存顶置视觉坐标、静置至少 3 秒记录抖动，然后计算局部 RMS、最大误差和静态标准差。

冻结建议门：

- 局部 RMS ≤ 1.0 cm；
- 最大误差 ≤ 1.5 cm；
- 静态位置标准差 ≤ 0.3 cm；
- 正式工作区避开图像边缘和支架遮挡区。

未通过时停止正式实验，重新标定或缩小工作区。不得通过放宽任务容差掩盖标定失败。

### 2.2 成功容差

成功容差必须在局部复核后、查看正式方法结果前冻结。推荐：

```text
成功半径 = max(2.0 cm, 3 × 局部静态标准差, 2 × 局部RMS)
```

同时预先设定最大允许值，例如不高于 3 cm。最终值写入 session manifest，此后不再修改。

## 3. 主物体与夹爪接触

### 3.1 主实验使用方形木块

推荐边长 5–7 cm、顶面平整、不易翻倒、无活动部件，全部主实验使用同一个编号物块和同一种场地表面。

当前仿真和 IPWM 对应平面滑动物体 pushing。普通球主要发生滚动，会改变接触、摩擦和停止距离，因此不得替代主方块。

### 3.2 球的地位

球只能作为主实验后的额外 OOD 演示：

- 单独标为 `ball-extra`；
- 不与方块合并统计；
- 不用于调节主方法；
- 只展示几何变化下的边界或泛化。

### 3.3 方块检测标记

木块顶部固定适合顶置和眼在手检测的高对比标记，可使用 ArUco/AprilTag。记录物块长宽高、质量、标记实际边长、标记中心偏移、标记轴方向和底面材料。

### 3.4 夹爪作为 pusher

主实验不抓取，只做非抓取推动。固定夹爪开度、接触面、接触高度、推动速度和方向。

优先在闭合夹爪前方安装平直刚性推板，使两指形成单一接触面。所有 trial 使用相同开度和附件，不得混用单指、双指和夹持。

## 4. 成功判定层级

### 4.1 单次 Trial 有效

必须满足：

- trial ID、方法、拓扑和 K 正确；
- Git commit、配置和 checkpoint 哈希完整；
- 初始位置在冻结容差内；
- 视频、视觉、舵机和动作日志完整；
- 时间戳单调且可以对齐；
- 正确加载对应视觉来源；
- 无人为接触和场地移动；
- 无文件覆盖或损坏。

视觉丢失、通信故障和安全中止属于结果，不能删除。只有预注册的操作性无效条件才允许重跑。

### 4.2 单次任务成功

```text
task_success =
    trial_valid
    AND no_safety_abort
    AND final_object_error <= frozen_success_radius
    AND movement_direction_correct
    AND object_inside_workspace
    AND object_not_tipped
```

### 4.3 方法成功

- D3、K25 下 object 主指标优于 matched Shared；
- 使用预注册 paired trials；
- paired 95% CI 支持正改善；
- 锁定坐标预测违例为零；
- 实际锁定漂移保持在安全门内；
- 安全中止率不高于 matched Shared；
- intact/D2 不出现不可接受副作用；
- 收益不是由少数异常 trial 驱动。

### 4.4 G3 结论等级

| 结果 | 允许结论 |
|---|---|
| G3-A、G3-B 都通过 | 动力学机制及眼在手闭环落地得到支持 |
| G3-A 通过、G3-B 失败 | 动力学机制成立，但眼在手视觉链未落地 |
| G3-A 失败 | 不能进入 G3-B 正式确认，先诊断执行或 sim-to-real |
| 只有成功视频 | 只能作为演示，不能称为 G3 证据 |

## 5. 冻结基线与参数

### 5.1 必须比较的方法

| 方法 | 作用 |
|---|---|
| Shared-K0 | 展示无适配的损伤影响 |
| Shared-matched-K25 | 决定性预算匹配基线 |
| Projection-only-K25 | 验证可行性本身不足以恢复物体动力学 |
| Full-IPWM-K25 | 完整方法 |

如现场时间有限，优先保留 Shared-matched、Projection-only 和 Full-IPWM。Shared-K0 不能替代 matched baseline。

### 5.2 禁止现场调节

- scale 1.38；
- grace 8；
- ramp 0.06；
- K25；
- 网络结构和 checkpoint；
- 成功容差；
- 安全门；
- trial 排除规则；
- 主指标。

发现实现错误时停止 session；修复后建立新 commit、新配置和新 session。旧数据保留，不与新版本混合。

## 6. 实验矩阵

### 6.1 G3-A：顶置视觉动力学验证

#### 调试，不进入主统计

| 条件 | 次数 | 目的 |
|---|---:|---|
| Intact overhead-oracle | 2–3 | 坐标、动作和接触方向检查 |
| D2 overhead-oracle | 1–2 | 锁定和安全门检查 |
| D3 overhead-oracle | 1–2 | 锁定和安全门检查 |

#### 正式确认

| 拓扑 | 方法 | K | 最低 paired 数 |
|---|---|---:|---:|
| Intact | Shared-matched / Full-IPWM | 25 | 5 |
| D2 | Shared-matched / Full-IPWM | 25 | 5 |
| D3 | Shared-K0 / Shared-matched / Projection-only / Full-IPWM | 0/25 | 10 |

D3 是核心。每个初始状态和目标形成一个 matched block，各方法使用相同初始区域、目标和动作预算。

### 6.2 G3-B：眼在手自主闭环

只有 G3-A 通过后才能开始。

#### 视觉资格测试

- 静态 9 点检测；
- 夹爪接近时检测；
- 接触前后检测；
- 标记可见率；
- 最长连续丢失时间；
- 与顶置真值的相对位移方向一致性；
- 坐标噪声和延迟。

建议门：

- 工作区物块检测率 ≥ 95%；
- 关键接触阶段检测率 ≥ 90%；
- 连续视觉过期不得超过 150 ms；
- 相对位移方向错误率接近零；
- 超门必须中止，禁止顶置补帧。

#### 正式确认

| 拓扑 | 方法 | K | 最低 paired 数 |
|---|---|---:|---:|
| Intact | Shared-matched / Full-IPWM | 25 | 5 |
| D3 | Shared-matched / Full-IPWM | 25 | 10 |

时间充足时再补 D2 各 5 个 paired blocks。

### 6.3 随机化

- 采集前生成并冻结方法顺序；
- 不得先跑完全部 Shared 再跑 IPWM；
- 使用 block randomization 平衡温升和摩擦漂移；
- 每次复位后自动检查初始状态；
- 中途不得根据结果修改顺序或参数。

## 7. 指标与统计

### 主指标

- D3 K25 object rollout RMSE；
- 最终 object position error；
- paired pushing success rate。

### 安全与副作用指标

- 锁定坐标预测违例；
- 真机锁定漂移；
- free-joint 和 pusher RMSE；
- 最大 raw current 和温度；
- 安全中止率；
- 视觉丢失率和最长丢失；
- 适配与控制运行时间。

### 统计规则

- 以 matched block 为配对单位；
- 保存并报告每个 trial 原始值；
- 报告均值、中位数和 paired difference；
- 使用 paired bootstrap 95% CI；
- 成功率报告分子和分母；
- aborted trial 必须保留；
- 同时报绝对误差和相对改善；
- 不因 CI 不理想而改变主指标或容差。

## 9. 安全停止条件

- 命令或反馈超时即停止；
- 视觉状态超过 150 ms 未更新即停止；
- raw current、温度或锁定漂移越过冻结门即停止；
- 物块或夹爪离开安全工作区即停止；
- 轨迹方向明显错误即停止；
- 异响、卡死、剧烈抖动或碰撞风险由现场人员立即物理断电。

`400 raw` 只是项目保守软件守护值，不是力或已标定额定电流。首次接触实验至少两人在场。

## 10. 到实验室后的执行顺序

### Session 0：布置

1. 固定机械臂、夹爪推板和眼在手相机；
2. 确认顶置相机与 FIRA 标定产物；
3. 固定水平相机和光照；
4. 测量物块、接触面与工作区；
5. 拍摄系统照片；
6. 创建 manifest，记录 commit 和哈希。

### Session 1：安全与坐标

1. 检测串口和摄像头；
2. 复核急停、零点、方向和软限位；
3. 完成顶置视觉局部 9 点复核；
4. 冻结成功容差；
5. 运行 intact 空载、intact 接触、D2 和 D3 smoke tests。

### Session 2：G3-A

1. 冻结随机顺序；
2. 顶置视觉向各方法提供同一状态接口；
3. 完成 intact/D2 副作用和 D3 核心试验；
4. 每个 block 后检查数据；
5. 不根据中间结果调参；
6. 完成三份备份。

### Session 3：G3-B 视觉资格

1. 标定眼在手内参和相机—夹爪关系；
2. 完成静态、接近和接触检测；
3. 对比顶置真值的方向、尺度、延迟和丢失率；
4. 通过资格门后冻结视觉前端；
5. 未通过则停止，不进入正式 G3-B。

### Session 4：G3-B 正式确认

1. 顶置视觉只写评估日志，控制进程无读取权限；
2. 眼在手视觉向模型提供物体状态；
3. 按冻结顺序完成 intact/D3 paired trials；
4. 视觉过期时停止，不允许 oracle 回退；
5. 封存数据与哈希。

### Session 5：分析

1. 完整性检查；
2. 按预注册规则判定有效性；
3. 从原始行重算指标；
4. 生成 paired bootstrap；
5. 分开报告 G3-A 和 G3-B；
6. 生成表格、轨迹、关键帧和补充视频；
7. 判定 Pass、Partial Pass 或 Fail。

### 只有 G3-A 通过

允许：在标定顶置视觉提供状态的条件下，IPWM 在真机 D3 pushing 中相对预算匹配 Shared 改善物体动力学预测或任务结果。

不允许：已经完成眼在手自主闭环部署。

### G3-A 和 G3-B 都通过

允许：IPWM 的动力学机制在独立顶置真值下成立，并在只使用眼在手视觉与舵机状态的自主闭环中保留收益。

### G3-A 通过但 G3-B 不通过

应写：动力学机制得到真机支持，但眼在手视觉前端或闭环集成仍是系统瓶颈。

### 两阶段均不通过

不得包装为成功。必须区分机械执行、坐标映射、视觉前端和模型 sim-to-real 误差，并保留全部失败数据。

---

## 15. 一句话方案

先用 FIRA 顶置视觉在相同状态输入下公平验证 IPWM 相对 matched Shared 的真机动力学收益；通过后，再将顶置相机隔离为独立裁判，由眼在手相机完成物块检测和闭环 pushing。主对象固定为方形木块，水平相机只负责接触与安全录像。
