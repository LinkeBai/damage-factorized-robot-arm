# G3 真机实验室携带清单与使用说明

> 目标：确保到学校实验室后能够完成眼在手单摄像头条件下的 G3 真机 pushing 验证，不因缺少线材、固定件、视觉标记或记录工具返工。
>
> 建议将物品分为三个包：机械臂箱、电子设备包、实验耗材包。出发前逐项勾选。

## 1. 机械臂与控制系统

### 必须携带

- [ ] 飞特 ST3215 五自由度机械臂本体
- [ ] 夹爪或末端推杆
- [ ] 机械臂底座
- [ ] 底座固定夹具、螺栓或桌面夹
- [ ] 舵机控制板
- [ ] USB—串口/TTL 转接器
- [ ] 机械臂专用电源及电源线
- [ ] 控制板与舵机总线连接线
- [ ] USB 数据线及备用线
- [ ] 备用舵机线或延长线
- [ ] 物理断电开关或带开关插排

使用要求：

- 机械臂底座必须刚性固定，不能只靠自重放在桌面上。
- 正式实验期间不得移动底座。
- 推杆从物块侧面接触，避免遮挡物块顶部标记。
- 上电前检查舵机 ID、方向、零点和软限位。
- 建议先连接数据线，再接动力电源。
- 操作者必须能立即触及物理断电开关。
- 不使用松动、破损或接触不良的线缆。

### 建议备件

- [ ] 备用 ST3215 舵机一只
- [ ] 备用舵盘或舵机臂
- [ ] 常用螺丝、螺母和垫片
- [ ] 备用控制板
- [ ] 备用 USB—串口转接器
- [ ] 备用保险丝
- [ ] 杜邦线、扎带和螺丝收纳盒

## 2. 电脑、软件与数据备份

### 必须携带

- [ ] 已安装项目环境的笔记本电脑
- [ ] 笔记本电源适配器
- [ ] 鼠标
- [ ] 足够长的插线板
- [ ] 带独立供电的 USB Hub，推荐
- [ ] 至少 50–100 GB 可用磁盘空间
- [ ] 项目仓库最新副本
- [ ] Python 虚拟环境或依赖安装文件
- [ ] 五种子冻结模型与 matched baseline checkpoint
- [ ] 真机配置、关节映射和安全限制文件
- [ ] 摄像头和 USB—串口驱动的离线安装包

建议提前保存的依赖：

- [ ] Python、PyTorch、NumPy、SciPy、PyYAML
- [ ] pyserial
- [ ] 包含 `cv2.aruco` 的 OpenCV contrib
- [ ] FFmpeg
- [ ] 摄像头驱动和串口驱动

使用要求：

- 不假设实验室网络一定可用。
- 出发前运行完整测试并保存结果。
- 正式采集前记录 Git commit。
- 实验期间不更新依赖、不更改模型参数、不切换代码版本。
- 当前审计分支为 `codex/g2-evidence-freeze`。

### 数据备份

- [ ] 移动硬盘或大容量 U 盘
- [ ] 第二个备份 U 盘，推荐
- [ ] 云盘账户，条件允许时使用
- [ ] 读卡器，如摄像设备需要

每个 session 完成后至少保留三份：电脑本地、移动硬盘、云端或第二 U 盘。

## 3. 眼在手摄像头

- [ ] 眼在手摄像头
- [ ] 刚性摄像头固定支架
- [ ] 摄像头 USB 线及备用线
- [ ] USB 延长线
- [ ] 扎带或理线套
- [ ] 擦镜布和镜头清洁工具

使用要求：

- 相机必须刚性安装，不能靠松软胶带悬挂。
- 相机与末端的相对姿态标定后不得改变。
- 线缆沿机械臂固定，但每个关节处保留运动余量。
- 上电前手动检查全行程，保证线缆不拉紧、不缠绕、不进入夹点。
- 尽量关闭自动对焦，固定焦距、曝光和白平衡。
- 推荐 1920×1080、30 FPS；延迟过高时可降至 1280×720。
- 记录实际分辨率、帧率、曝光和摄像头设备编号。

## 4. 第三视角录像设备

手机不参与模型输入，只用于论文展示、安全审查和故障复盘。

- [ ] 手机
- [ ] 手机充电器
- [ ] 充电宝
- [ ] 手机三脚架及夹具
- [ ] 足够的手机存储空间
- [ ] 第二部手机，可选

使用要求：

- 手机固定在侧前方，完整拍到机械臂、物块、桌面和操作人员。
- 不手持录像。
- 推荐 1080p、30 FPS。
- 每次 trial 开始前让画面拍到 trial ID 卡片。
- 最好整段 session 连续录像，保留失败和安全中止过程。
- 手机视频不能替代眼在手原始视频与机器日志。

## 5. 物块与推动表面

### 物块

- [ ] 至少两个规格一致的刚性木块
- [ ] 一个备用物块
- [ ] 直尺或游标卡尺
- [ ] 电子秤，建议
- [ ] 物块编号标签
- [ ] 细砂纸，可选

推荐物块条件：

- 近似方形或长方形，顶面平整；
- 尺寸约 5–7 cm；
- 不易倾倒，无滚轮、软垫或活动部件；
- 表面不过度反光；
- 顶面能贴下 3–5 cm 的 ArUco 标记。

每个物块记录：长、宽、高、质量、材料、底面材质、标记实际边长、标记中心相对物块中心的偏移，以及标记轴与物块方向的对应关系。

正式主结果尽量固定使用同一个物块，其他物块仅用于额外泛化验证。

### 推动表面

- [ ] A2/A3 切割垫、薄木板或哑光 PVC 板
- [ ] 防滑垫
- [ ] 备用摩擦表面
- [ ] 酒精棉片或清洁布

使用要求：

- 正式实验全程使用同一块表面。
- 实验前清除灰尘和碎屑。
- 推动轨迹不能跨越不同桌面材料。
- 实验板必须固定，不能随物块移动。
- 记录表面材料和清洁方式。

## 6. 需要打印的视觉材料

所有图案按“实际尺寸/100%”打印，关闭“适应页面”。打印后必须用直尺测量真实尺寸。

### A4 棋盘格

- [ ] A4 棋盘格一张
- [ ] 备用棋盘格一张
- [ ] 平整硬纸板或泡沫板
- [ ] 胶棒或双面胶
- [ ] 直尺

用途：在 G3 开始前标定摄像头内参，包括焦距、光学中心和镜头畸变。棋盘格不需要留在正式推动桌面上。

要求：纸面贴平、不翘曲；从不同距离、角度和画面位置拍摄约 20–40 张；将实测方格边长写入标定配置；目标重投影 RMS 不高于约 1 px。

### 桌面 ArUco

- [ ] ID 0：8–10 cm
- [ ] ID 1：8–10 cm
- [ ] ID 2：8–10 cm
- [ ] ID 3：8–10 cm
- [ ] ID 4、5：备用
- [ ] 每个标记至少一份备用件

用途：定义桌面世界坐标系，消除眼在手摄像头随机械臂运动产生的画面漂移。

安装要求：

- 固定在工作区四周，不位于必然遮挡或接触区域；
- 所有标记处于同一平面；
- 正式实验期间不得移动；
- 测量黑色外框实际边长；
- 测量并记录每个标记中心在桌面坐标系中的位置。

### 物块 ArUco

- [ ] ID 10：3–5 cm
- [ ] ID 11、12：备用
- [ ] 同一 ID 的备用打印件

用途：估计物块的 `x/y/yaw`，形成 object rollout 的真机观测。

安装要求：平整贴在物块顶面并尽量居中；不能超出边缘；不使用强反光透明胶覆盖图案；推杆从侧面接触，避免遮挡顶部。

### 可选方格纸

- [ ] A3 方格纸或厘米网格切割垫

用途：辅助复位、标记目标和展示尺度。它不能代替 ArUco 世界坐标测量。

## 8. 光照与视觉辅助

- [ ] 台灯或 LED 补光灯
- [ ] 灯具支架
- [ ] 延长线
- [ ] 白色遮光板或普通白纸
- [ ] 黑色哑光布，可选
- [ ] 遮光窗帘或纸板，可选

使用要求：

- 避免自然光随时间快速变化。
- 避免标记表面反光。
- 避免机械臂阴影持续覆盖桌面标记。
- 正式 session 开始后不改变灯的位置或亮度。
- 拍摄一张无遮挡空场景照片记录光照条件。

## 9. 安全物品与规则

- [ ] 物理急停或可立即断电的开关
- [ ] 带开关插排
- [ ] 护目镜，建议
- [ ] 绝缘手套，可选
- [ ] 警戒胶带或桌面安全边界
- [ ] “实验中，请勿触碰”提示牌
- [ ] 急停操作说明纸
- [ ] 过流、过温和通信故障处置表

安全规则：

- 首次接触实验建议至少两人在场：一人观察机械臂，一人监控电脑和遥测。
- 身体、头发和衣物远离关节夹点。
- 上电后不把手伸入运动区域。
- 异响、抖动、卡死、过流、温升、通信丢失或视觉丢失时立即停止。
- 软件中止不能替代物理断电。
- `400 raw` 是项目保守软件守护值，不是力或已标定的额定电流。
- 首次从 intact、空载、低速开始，禁止直接运行 D3 pushing。

## 12. 冻结的最低实验矩阵

| 条件 | 方法 | K | 最低重复 |
|---|---|---:|---:|
| Intact | Shared | 0 | 5 |
| Intact | IPWM | 25 | 5 |
| D2 | Shared matched | 25 | 5 |
| D2 | IPWM | 25 | 5 |
| D3 | Shared | 0 | 10 |
| D3 | Shared matched | 25 | 10 |
| D3 | IPWM | 25 | 10 |

最低合计 50 次。时间不足时优先完成 D3 三组，然后补 intact/D2 副作用验证。

正式 trial 顺序需预先随机化，禁止先跑完所有 shared 再跑 IPWM。各方法保持相同初态、目标、动作或规划预算、K、停止条件、桌面、光照和相机设置。

## 15. 到实验室后的执行顺序

1. 布置并刚性固定机械臂、实验板、相机和第三视角手机；
2. 检查供电、串口、零点、方向、软限位和物理断电；
3. 完成相机内参标定；
4. 固定桌面 ArUco 并建立桌面坐标系；
5. 标定物块标记及物块几何关系；
6. 运行真机 readiness audit；
7. 执行 intact 空载低速 smoke test；
8. 执行 intact 低速 pushing；
9. 执行 D2 锁定 smoke test；
10. 执行 D3 锁定 smoke test；
11. 按预先随机化清单运行正式 paired trials；
12. 每个 session 结束后立即完成数据校验和三份备份。
