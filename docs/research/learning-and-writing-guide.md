# 学习路线与写论文指南

> 前提：已有自制简易机械臂，预算几百元级，不强求CCF。

## 一、自制臂接入模仿学习的检查单

流水线（LeRobot/ACT）对硬件只有三个硬要求：

1. **能实时读取每个关节的实际角度**（≥30Hz）—— 状态输入，最关键
2. **能发送目标角度指令** —— 动作输出
3. **一个看得到工作区的USB摄像头**

按你们臂的电机类型分三种情况：

- **情况A：总线舵机（飞特STS/SCS、幻尔、Dynamixel等，可读回位置）**
  最理想。给LeRobot写一个驱动类（继承`Robot`接口，实现连接/读状态/发动作，参照[SO-101驱动源码](https://github.com/huggingface/lerobot)，一两百行Python）。若用的恰好是飞特STS3215，几乎可直接改SO-101配置文件。
- **情况B：PWM舵机（SG90/MG996R，读不回位置）**
  - 省事方案：换成飞特STS3215（约¥250-350），一步到位变情况A
  - 零花费变通：用发出的指令值代替实际值当状态（开环近似）。ACT主要靠图像输入，很多任务照样能学；先跑通流程再决定是否换舵机
- **情况C：步进电机**：按B处理，或加AS5600磁编码器（¥5/个）补反馈

## 二、没有leader臂时怎么采演示数据

1. **再做一只无动力同构副本当leader**（GELLO思路）：关节装便宜舵机或AS5600编码器，人拖动它、follower跟随。成本¥100-300，**这一步本身就能出论文**
2. **键盘/手柄遥操作**：LeRobot原生支持，零成本，采精细任务数据较别扭
3. **拖动示教**：舵机断电、人手直接拖follower记录轨迹（需情况A）

## 三、学习路线（约6-9个月）

### 阶段1：基础（1-2个月）
- 深度学习基础（CS231n级别）+ 模仿学习/强化学习入门（Spinning Up）
- 机器人学只需概念级：正/逆运动学、坐标变换。ALOHA一派的卖点就是用关节空间映射绕开复杂运动学
- 精读：ACT、Robot Learning Tutorial、Diffusion Policy、GELLO（见论文清单第1-4篇）

### 阶段2：仿真上手（1-2个月，¥0）
- 装LeRobot，仿真里跑通ACT训练→评测全流程（自带ALOHA/PushT任务）
- 从HuggingFace Hub下载社区SO-100/SO-101数据集训一遍，熟悉数据格式
- GPU：Colab/Kaggle免费额度够训ACT；不够租AutoDL约¥1-2/小时

### 阶段3：实机复现（1-2个月）
- 把自制臂接入LeRobot（第一节的驱动工作）
- 配leader臂或用键盘遥操作，采50条演示，在自制臂上复现ACT完成2-3个抓放任务
- 仿真到实机踩的坑本身就是研究素材

### 阶段4：找创新点（贯穿）
适合自制臂的切口，按推荐排序：
- **数据侧**：更便宜/更高效的演示采集（GELLO/UMI/ARMimic这条线空白还很多，如加触觉、力反馈）
- **算法侧**：ACT/Diffusion Policy针对性改进（长程任务、失败恢复、多模态输入，参照Bi-ACT的做法）
- **跨机体**：用公开的昂贵臂数据（Open X-Embodiment）预训练→迁移到自制臂，最贴合"简易臂做复杂臂任务"的题目
- **系统侧**：证明某类"以前认为必须昂贵硬件"的任务能被简易臂+学习方法完成，"能力民主化"故事

## 四、发表路线（不限CCF后按性价比排序）

1. **RSS/CoRL的Workshop**：4页短文，对学生极友好，录取率高，第一篇工作最佳练手场，之后可扩成正会论文
2. **RA-L**（IEEE Robotics and Automation Letters）：审稿约3个月、滚动投稿、可关联ICRA/IROS发表，圈内认可度高
3. **ICRA（CCF-B，9月中截稿）/ IROS（CCF-C，3月初截稿）正会**：两会截稿错开半年，天然形成被拒转投节奏
4. **开源社区路线**：改进做成LeRobot的PR / HuggingFace模型+数据集 + arXiv技术报告。社区影响力对申研/找工作不亚于一篇C会论文

## 五、论文写作要点（机器人会议8页双栏）

- **故事线**：昂贵硬件的能力X如何被"低成本系统+算法Y"复现
- **实验必备**：与ACT和Diffusion Policy两条基线对比；消融实验；失败案例分析
- **评测规范**：每任务≥20-50次评测报成功率；报告演示数据量（数据效率是本领域核心卖点）；统计规范参照论文清单#12
- **视频附件必做**：这个领域视频几乎是硬性要求
- **节奏**：截稿前8周定实验表格 → 前4周初稿 → 前2周请人过Intro（审稿人平均只细读Intro和实验图表）
- **心态**：ICRA/IROS录取率约40-45%，首投被拒按意见补实验转投下一个，两轮内中稿是正常轨迹
