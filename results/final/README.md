# Final-result boundary

This directory contains historical frozen aggregate outputs from several
project stages. A filename under `results/final/` does not automatically make
it evidence for the current paper claim; the authoritative claim-to-evidence
boundary is `PROJECT-PLAN-V6.md` and `LATEST-STATUS.md`.

`v7-full-eval-seed7.csv` is a legacy single-seed smoke output refreshed during
the directional-Push correction. It is retained for auditability but is not
referenced by the current FCCM-IPWM Stage-0 claim, and it must not be reported
as an independent or confirmation result without a frozen generator command
and matched rerun.
