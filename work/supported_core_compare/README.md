## 物理修订与保留的证据

`protocol-history`保留原始协议与修订理由。v1初态/支撑合法，但正式±0.8动作仍出现过深工具桌面软接触和软限位越界，未启动正式训练或数据采集。

同320个开发初态/输入比较了时间步和接触/限位设置。仅缩小时间步不足以消除默认约束柔软性；v2明确将几何接触和关节限位solref设为[.004,1]，solimp前三项设为[.99,.9999,.001]，内部时间步0.25ms，观测步仍5ms。质量、几何、摩擦、阻尼、执行器、锁参数与动作幅度不变。该修订属于理想化软接触模型选择，不是通过硬件标定的材料刚度。

0.5ms到0.25ms的随机控制终点差异：均值0.422mm、95百分位1.522mm、最大2.737mm；全负极端控制最大10.223mm。全部原始轨迹保留，不能宣称所有情况下达到亚毫米数值收敛。新的物体竖直运动完整记录，但14维模型输入仍省略z/vz。

`physics-gate.json`明确哪些检查通过、哪些更强物理主张尚未证实。正式采样与规划保留每个内部步的接触/限位/支撑诊断，失败不丢弃。
